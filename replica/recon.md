# Recon — CareNav (carenavindia.ai) vs ClaimOne
Sources: carenavindia.ai home (How it works, Security, FAQ, product screens), /blog/carenav-now-live-on-nhcx. Public pages only; no account, no code.

Core loop: Document Doctor -> Capture -> Validate -> Submit (NHCX) -> Track -> Resolve queries -> Close -> Reconcile.

Screens seen: S01 Doctor insight (WhatsApp), S02 Integration choice (HL7/FHIR or WhatsApp), S03 Paper checklist (Valid/Review),
S04 Sent via NHCX, S05 Claims dashboard (counters, due-time rows, priority tag, monthly donut), S06 Query + drafted reply,
S07 WhatsApp assistant (status, confirm & close), S08 Payments panel (Settled / On track / Needs review).

Gaps, build order: see features.csv. Size: M (3-5 weeks) for the no-cost items; NHCX/WhatsApp/AI items depend on onboarding and paid keys.
